# 🚀 FundPilot AI

**FundPilot AI** is a powerful LLM-driven platform for fund managers, GPs, and LP liaisons. It automates the creation of deal memos, capital calls, distributions, legal summaries, fund metrics, and LP updates — all from a single data upload.

---

## 🌐 Live Demo

👉 [Launch FundPilot AI](https://fundpilot-ai.streamlit.app)

---

## 🧠 Features

| Module               | Description |
|----------------------|-------------|
| 📝 Deal Memo Writer   | Generates investor-ready memos from deal data |
| 📁 Legal Summarizer   | Translates fund docs into plain English |
| 💵 Capital Call       | Creates LP-ready capital call notices |
| 💸 Distribution Notice| Drafts distribution notices with key metrics |
| 📈 Metrics Dashboard  | Computes IRR, MOIC, DPI, TVPI with explanations |
| 📨 LP Update Writer   | Crafts quarterly updates for investors |
| 💬 GP/LP Q&A Simulator| Answers tough LP questions based on fund context |

## 💬 Why FundPilot AI?

FundPilot AI handles the tedious, high-stakes fund communications and analysis so you can focus on investment strategy. From pitch to payout, it’s your AI-powered fund operations analyst.
